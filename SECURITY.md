# Security and privacy

To report a security vulnerability, use GitHub's private vulnerability-reporting feature for this repository if available. If it is unavailable, contact the maintainer through their GitHub profile without posting sensitive details publicly; arrange a private channel before sharing a reproduction.

Do **not** put real server passwords or `AdminPassword`, public IP addresses, saves, player IDs, unsanitized logs, or `PalWorldSettings.ini` files containing secrets in public issues or pull requests. Remove or replace sensitive values and local paths before sharing diagnostics.
