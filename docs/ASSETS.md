# Asset provenance

`PalServerManager.WinUI/Assets/ManagerIconSource.jpg` is artwork supplied by a project user. Its original creator and redistribution terms have not been independently established. The project did **not** create that illustration from scratch.

`ManagerIconCircular.png` is a circular, transparent crop derived from that supplied artwork. `tools/CreateIcon.ps1` packages it into `ManagerIcon.ico` at application-icon sizes. These are technical derivatives, not independently licensed original artwork. The circular PNG and ICO are retained as build assets; no official Palworld logo or wordmark asset is included.
